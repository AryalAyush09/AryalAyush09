# Hi, I'm Ayush Aryal 👋

### Full-Stack Software Engineer | System Architecture | Backend & Database Engineering

I am a **Full-Stack Software Engineer** with a strong focus on designing **scalable backend architectures, reliable distributed services, and performance-efficient database systems**.

My primary expertise lies in **Java, Spring Boot, PostgreSQL, and Redis**, with practical experience developing secure REST APIs, optimizing database queries, implementing search and recommendation systems, and deploying applications to Linux-based infrastructure.

I also work with **React, Next.js, and TypeScript** to build complete, API-driven applications.

I enjoy solving complex engineering problems, designing maintainable architectures, and taking systems from development to deployment.

## 🧠 Engineering Focus

- **System Architecture:** Modular applications, distributed service integration, scalability, and asynchronous processing.
- **Backend Engineering:** RESTful APIs, authentication, authorization, business logic, and service reliability.
- **Database Engineering:** PostgreSQL query optimization, indexing strategies, relational modeling, and transaction management.
- **Search & Recommendations:** Full-text search, trigram similarity, relevance ranking, database-driven recommendations, and Bloom filters.
- **Testing & Reliability:** JUnit, Spring Boot Test, unit/integration testing, structured logging, and debugging.
- **Infrastructure & Deployment:** Linux VPS, Docker, Nginx, server configuration, and production troubleshooting.
- **AI Integration:** Spring AI, Retrieval-Augmented Generation (RAG), semantic search, and LLM API integration.
